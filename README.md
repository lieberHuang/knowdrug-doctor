# 医伴 MedLink · 医生学术工作台

无需构建、无运行时依赖的 HTML / CSS / JavaScript 交互原型。入口为 `dist/index.html`。

## 启动

在本目录执行 `python3 -m http.server 8080 --directory dist`，打开 `http://localhost:8080`。也可以直接打开 `dist/index.html`，但推荐问题的复制功能需要安全上下文。

## 已实现

- 移动端 App 布局：底部三栏导航（首页 / 学术 / 我的）、大字号列表、触控按钮、底部资料弹层和首页内嵌的药品助手。大屏仍保持移动布局。
- 无需登录即可进入首页；右上角展示医生姓名与科室。
- 虚拟医药代表欢迎：AI 生成肖像、中文配音、同步字幕、播放/暂停/静音/进度控制；向下滑动自动收起，折叠后显示“联系我”，打开拨号弹窗；首页返回顶部或重新点击首页时，恢复显示视频。
- 单药品问答、推荐问题切换、连续追问、规则回复、资料入口、会话记录。
- 病历点评：病历列表、详情、医生点评、发布、图片上传与黑块遮挡；已发布内容保存在当前浏览器的 IndexedDB。
- 相关指南与文献：搜索、分类、阅读详情、收藏。
- 问答记录和收藏保存在当前浏览器 localStorage；没有服务器或跨设备同步。

## 原型边界

这是产品交互原型。应用内不包含登录和身份认证流程。欢迎区为生成肖像配中文旁白的数字人视频交互演示，并非口型同步的真人数字人视频。尚未接入真实数字人视频服务、AI 模型、医学知识库、临床诊断系统或实时文献源。拨号弹窗显示临时示例号码 13800000000；呼叫链接使用 tel: 协议，由用户手动发起。请在 app.js 的 representative.phone 中替换实际业务号码。页面采用正式产品文案；问答仍为本地规则，指南与文献仍为阅读框架，不能作为已核验的临床资料。

## 正式接入位置

- 数字人：将 `.hero-visual` 中的肖像和 audio 组合替换为 `<video>`，接入按医生匹配的代表视频；沿用播放与折叠交互。
- 问答：替换 `answerFor()` 与 `askQuestion()` 的规则延迟部分，接入带来源的单药品知识库 API。
- 指南/文献：替换 `resources` 演示数据，使用可核验的来源、版本与发表日期。
- 病历点评：对接病例列表、评论与脱敏图片的后端存储服务。

## 视觉资产

`dist/assets/representative.png` 使用内置 image_gen 生成。提示词：一位约 30 岁的虚构中国女性医药代表，黑色齐肩发，奶油色西装与浅色内搭，淡青色胸针，半身、温和自然微笑，明亮现代医学学术空间、磨砂玻璃和浅鼠尾草绿背景，柔和自然光，无文字、品牌或水印。

`dist/assets/welcome.m4a` 使用 macOS Tingting 中文语音生成，旁白内容为欢迎医生并介绍平台学术功能。

使用系统中文字体。肖像与语音均为本地资产。

移动端交互：Enter 保留换行，点击“发送”提交；硬件键盘可用 Ctrl/Cmd + Enter。适配安全区域与软键盘，支持系统返回及页面返回。

问答区名称：knowdrug 知药-医生版。已移除通知入口和各页面的装饰性辅助文案。

首页结构：数字人视频 → knowdrug 知药-医生版 → 病历点评 / 相关指南 / 最新文献 → 药品资料及提问。已移除独立问答页面，历史会话与新建对话统一回到首页助手。

已清理宣传口号、角色副标题、重复助手名称及空状态辅助说明；JS/CSS 资源使用版本标识以避免旧资源缓存。

当前演示药品统一为日达仙。相关条目为资料阅读框架与交互样例，不增加具体适应症或用药剂量信息。

## 病历讨论模块

- 入口显示全部 / 待点评 / 我的发布，可搜索标题与内容。
- 每份病历支持查看正文和图片、发表医生点评并持久保存。
- 发布流程包含文字与图片脱敏提醒、身份字段检测、人工确认和发布复核。
- 照片在浏览器中解码并重新导出，最多6张；使用“遮挡信息”拖动添加不透明黑块，支持撤销。保存后遮挡合入图像像素。
- 原始图片与未发布表单仅保留在页面内存；发布时仅保存最终处理后的图片，不保存原文件名、原始图片或遮挡编辑历史。
- 本项目未接入 OCR 或自动患者信息识别；人工确认不能替代逐张检查。发布内容和点评只保存在当前浏览器，不会共享到其他设备或同步至代表端。
