# knowdrug 知药 · 医生端

独立的 HTML / CSS / JavaScript 移动端交互项目，入口为 `dist/index.html`。线上不需要 npm 或运行时依赖。

在本目录执行 `python3 -m http.server 8080 --directory dist` 可启动本地服务。

- 首页：三条独立的数字人视频，可上下滑动逐屏切换；只播放当前视频。支持暂停、声音切换、进度拖动和联系代表。输入、回答或其他弹层打开后暂停并锁定背景视频；离开首页及页面隐藏时停止播放。
- 问我更多：右下角悬浮按钮展开文字/语音输入横幅，文字可修改后手动发送。发送后拉起底部回答卡片；每条回答提供三个可点击的“猜你想问”，支持继续提问、复制回答及查看药品资料。
- 语音：接入浏览器 SpeechRecognition / webkitSpeechRecognition，使用中文识别并处理权限拒绝、无结果、关闭后的迟到回调；关闭横幅、发送或离开页面均终止识别。识别依赖浏览器、麦克风授权及其语音服务，不支持的浏览器提示使用系统键盘语音输入，文字输入始终可用。
- 导航：不显示底部 tab 栏。右上角医生姓名打开右侧抽屉，提供“患者洞察”和“我的”；抽屉支持关闭按钮、遮罩和系统返回，选择页面后收起抽屉。学术页面已移除，旧页面标识返回首页。
- 患者洞察：直接展示全部患者的年龄、性别、地区、疾病进展分布；移除“筛选人群”卡片，保留图表维度切换及提问主题选择。
- 我的：查看本机问答记录及联系代表；旧问答记录保留并迁移为新的回答卡片。系统返回依次关闭输入横幅、回答或叠加资料弹层。

## 数据与媒体

- 保留医生端 `medlink-` localStorage 命名空间，不修改代表端存储。没有真实身份认证或跨设备同步。
- 问答为浏览器本地的资料阅读框架，未接入真实医学模型、知识库或实时文献源，不提供具体剂量或适应症结论。
- `dist/video-feed.js` 保存视频主题、时长与分句字幕。`assets/feed-intro.mp4`、`assets/feed-reading.mp4`、`assets/feed-safety.mp4` 使用既有虚构代表肖像的轻微镜头运动及 macOS Tingting 旁白生成，编码为 H.264 + AAC；未接入口型合成或真人克隆服务。
- 三条视频分别介绍平台、资料查阅和用药信息核对。媒体为项目内资源，不使用外部播放器或视频 CDN。自动播放初始静音，浏览器若阻止播放可手动点击。
- 患者洞察为匿名合成分布，不包含患者身份资料。联系号码 13800000000 为临时配置，呼叫通过 tel: 交由用户发起。

## 检查

`npm ci && npm test` 运行 DOM 交互检查：滑动视频切换、播放互斥、播放器控制、悬浮横幅、语音事件/权限拒绝/不支持回退、语音迟到结果取消、底部回答卡片、每条回答的三个追问、历史保存与迁移、嵌套弹层返回、右侧医生菜单、无底部导航、患者洞察无筛选卡片、图表/主题切换和学术路由移除。

三个 MP4 文件已执行视频和音频完整解码检查。实际设备显示、麦克风和浏览器语音服务仍需实机体验。

## 手机兼容增强

- 使用测量的视口高度替代对动态视口单位的单一依赖，处理地址栏和软键盘变化；补充短屏、横屏及 320–360 px 窄屏样式。
- 对缺少原生 dialog 的浏览器提供本机弹窗回退，包含遮罩、焦点约束、关闭与嵌套弹层；对缺少 randomUUID 的浏览器使用 getRandomValues 生成标识，移除 Object.hasOwn / Array.at 依赖。
- 自动化检查模拟 320×568、360×640、375×667、390×844、430×932、480×800、667×375、844×390 视口以及键盘偏移，分别执行原生弹窗和回退弹窗的业务流程。该检查不进行真实浏览器像素布局。
- 当前浏览器预览服务超时，尚未完成 iPhone / 安卓 / 微信内置浏览器的实机截图验收；语音识别、录音和视频生成仍受浏览器能力及授权限制。
